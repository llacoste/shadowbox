# Shadowbox — AI Working Notes

Turns an image into N stacked SVGs sized for laser-cutting a [shadow-box-style 3D piece](https://preview.redd.it/i-want-to-create-a-layered-design-like-this-by-laser-v0-hvz1hrgntvka1.jpg). CLI + FastAPI/HTMX web UI on a shared Python core, distributed primarily as a Docker image (`ghcr.io/llacoste/shadowbox`).

## Architecture at a glance

Pipeline: `load → preprocess → engine.slice → vectorize → compose`.

- `preprocess.py` — opt-in `rembg` background removal + alpha-aware auto-crop. Engines never see raw uploads.
- `engines/` — pluggable slicers. `LuminanceEngine` is the only v1 implementation (equal / Otsu / k-means threshold modes). New engines implement the `SlicingEngine` Protocol in `engines/base.py` and register in `engines/__init__.py`.
- `vectorize.py` — binary mask → SVG path strings via `potracer`. Exposes `min_feature_size_mm` (potrace `turdsize`).
- `compose.py` — assembles per-layer SVG: outer frame, cut paths, kerf compensation, color semantics (red cuts / blue frame / black engraves), engraved layer number.
- `materials.py` — preset registry of common laser stock with kerf defaults.
- `preflight.py` — post-slice analysis: tiny features, solid layers, floating islands, aspect-ratio mismatch.
- `project.py` — JSON save/load of all settings + image SHA-256 (no bytes).
- `pipeline.py` — orchestrator. CLI and web both call `process()`.

## Conventions

- **SVG units are mm.** `viewBox` is in pixel space, `width`/`height` carry the mm. Don't break this; laser software depends on it.
- **Color semantics are load-bearing.** Red `#FF0000` = cut, blue `#0000FF` = frame (cut last), black `#000000` = engrave. Matches LightBurn defaults.
- **Don't add new dependencies without a note in this file.** Small-deps discipline. If you must, pick well-maintained Hex/PyPI packages and explain why.
- **Tests are unit-first.** Engine tests use synthetic gradients; preflight uses hand-crafted masks; web uses FastAPI TestClient. No network in tests — `rembg` is stubbed.
- **Fixtures stay tiny.** Anything in `tests/fixtures/` should be < 100×100 px and ideally generated by `tests/fixtures/generate.py` for determinism.

## Dev loop

All commands run inside the Docker image — no host Python install required:

```
just build          # docker build
just slice tests/fixtures/mountains.png --layers 5 --output tmp/
just serve          # FastAPI on :8000
just test           # pytest in container
just lint
just format-check
just typecheck
just shell          # /bin/bash inside the image
```

## Release

Bump `[project].version` in `pyproject.toml`, merge to `master`. CI's Deploy stage publishes `ghcr.io/llacoste/shadowbox:vX.Y.Z` + `:latest` and cuts a GitHub Release. Re-merges without a bump no-op.

## Things deliberately deferred

Depth-ML engine, DXF/PDF output, 3D WebGL preview, non-rectangular frames, assembly-PDF generation, multi-image batch. Architecture supports them; v1 doesn't ship them. See the plan in this repo's history for rationale.
